# Проверка Crossy

Проверено 10 октября 2026 года.

- `npm test`: 15 тестов Vitest 4.1.11 прошли.
- `npm run build`: многостраничная production-сборка Vite прошла.
- `npm audit`: 0 уязвимостей после обновления Vitest.
- `git diff --check`: ошибок пробелов нет.
- Chromium / Playwright CLI: поиск с регистром и пробелами, совместные URL-фильтры, назад/вперёд, выбор размера клавишей Space, сообщение при отсутствии размера, объединение повторного добавления и разделение размеров, изменение количества и итог.
- Проверены добавление/удаление избранного, сохранение после перезагрузки, пустая корзина, пустое избранное, пустая выдача, неизвестный товар.
- Проверены ошибки формы и фокус первого поля, обязательный адрес для доставки, успешная сводка, очистка корзины. При оформлении сетевых запросов отправки не было; контактные данные в localStorage отсутствуют.
- Проверены повреждённый JSON, неизвестные идентификаторы и работа при запрете localStorage в отдельном браузерном контексте.
- На viewport 375×812 все пять страниц без горизонтального скролла; панель фильтров закрыта по умолчанию и раскрывается с клавиатуры.
- Просмотрены скриншоты главной при 1440×1000 и полного мобильного каталога. Артефакты находятся локально в `output/playwright/` и не включены в Git.
- На VPS проверены 33 адреса HTML, JavaScript, CSS, шрифтов и изображений: HTTP 200. Браузерные сценарии повторены на production-сайте. Ошибок и предупреждений консоли на опубликованном сайте не обнаружено.
- `docker exec crossy-nginx nginx -t`: конфигурация корректна.
- Внешняя доступность: HTTP 200 из Израиля, Нидерландов и Словении. [Отчёт Check-Host](https://check-host.net/check-report/50271150k5e6).

Адрес: http://193.233.126.148:8081/ . Выдаётся production-сборка через отдельный Nginx, сервер разработки для публикации не используется. Другие сайты и их конфигурации не изменялись. Домена и HTTPS для Crossy нет.

Ограничения проверки: один браузер Chromium, мобильный viewport вместо физического телефона; отдельная проверка экранным диктором, Safari и Firefox не выполнялась.
